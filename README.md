# Eden King & Queen Guest House & Spa

Static website with property photos, an opening film and WhatsApp booking requests.

Run `node preview.mjs`, then open http://127.0.0.1:4173.

The deployable site is in dist/. Room types and advertised rates are in dist/app.js. Contact links are in dist/index.html and dist/app.js. Eden confirms availability and final prices on WhatsApp.
